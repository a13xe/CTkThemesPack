CTkThemesPack
=======================================================================================================================================

Este repositorio contiene archivos JSON que definen paletas de colores personalizadas para la [librería CustomTkinter](https://github.com/TomSchimansky/CustomTkinter), permitiéndote personalizar de forma rápida y sencilla la apariencia de tus aplicaciones basadas en customtkinter.

_**¿Cómo usarlo?**_

- Crea una carpeta [themes](https://github.com/a13xe/CTkThemesPack/tree/main/themes) en tu proyecto, 
- Deposita en ella los archivos .json de tu preferencia,
- Luego utiliza el método .set_default_color_theme().

</div>

```python

customtkinter.set_default_color_theme("themes/breeze.json")
```
